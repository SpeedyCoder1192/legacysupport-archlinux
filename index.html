About This Project

This project provides a user-friendly script designed to add legacy CPU and GPU support to Arch Linux installations. It's ideal for USB-based or portable setups intended to run on older or varied hardware.

The script detects older AMD and Intel hardware and installs the linux-lts kernel for improved compatibility.

Whether you're booting on a modern or older PC, this project aims to make Arch Linux accessible everywhere—especially where official support might be lacking.
